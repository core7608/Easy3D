# 🎨 Easy3D - برنامج التصميم ثلاثي الأبعاد

## مقدمة

**Easy3D** هو برنامج بسيط وخفيف لتصميم الأشكال ثلاثية الأبعاد، مصمم خصيصاً للمبتدئين والأجهزة الضعيفة.

### لماذا Easy3D؟

| الميزة | Easy3D | Blender |
|--------|--------|---------|
| **متطلبات النظام** | منخفضة جداً | عالية |
| **كرت الشاشة** | لا يحتاج | مطلوب |
| **سهولة التعلم** | سهل جداً | صعب |
| **الحجم** | أقل من 1 ميجا | أكثر من 300 ميجا |
| **اللغة** | عربي بالكامل | إنجليزي |

---

## التثبيت

### المتطلبات
- Python 3.6 أو أحدث
- tkinter (مثبت مسبقاً مع Python)

### طريقة التشغيل
```bash
python3 easy3d.py
```

## واجهة البرنامج

### شريط الأدوات العلوي
- **ملف**: جديد، حفظ، فتح، تصدير
- **تحرير**: تراجع، إعادة، تكرار، حذف
- **إضافة**: إضافة أشكال جديدة
- **عرض**: تغيير زاوية الكاميرا

### الأدوات الأساسية

| الأداة | الرمز | اختصار | الوظيفة |
|--------|-------|--------|---------|
| اختيار | 🔍 | W | تحديد الكائنات |
| تحريك | ✥ | G | نقل الكائنات |
| تدوير | ↻ | R | تدوير الكائنات |
| تحجيم | ⤡ | S | تكبير/تصغير |

### الأشكال المتاحة

| الشكل | الرمز | الوصف |
|--------|-------|-------|
| مكعب | ⬜ | شكل مكعب بـ 6 أوجه |
| كرة | ⭕ | كرة بـ 12 قطاع |
| أسطوانة | 🔵 | أسطوانة دائرية |
| مخروط | 🔺 | مخروط بقاعدة دائرية |
| مستوي | ▸ | سطح مسطّح |
| حلقة | 💍 | حلقة دائرية |

## الاختصارات

### الأدوات
```
W        → اختيار
G        → تحريك
R        → تدوير
S        → تحجيم
```

### الكاميرا
```
عجلة الماوس    → تقريب/تبعيد
الزر الأوسط    → دوران حول المشهد
Shift + زر وسط → تحريك الكاميرا
```

### العمليات
```
Shift+D    → تكرار الكائن
Delete/X   → حذف الكائن
Ctrl+Z     → تراجع
Ctrl+Y     → إعادة
Ctrl+S     → حفظ
Ctrl+N     → مشروع جديد
Ctrl+O     → فتح مشروع
```

### زوايا الكاميرا (Numpad)
```
1        → أمامي
Ctrl+1   → خلفي
3        → يمين
Ctrl+3   → يسار
7        → علوي
Ctrl+7   → سفلي
5        → منظور/écran
```

## كيفية الاستخدام

### 1. إنشاء كائن جديد
```
من القائمة: إضافة → مكعب/كرة/أسطوانة...
من شريط الأدوات: اضغط على أيقونة الشكل
```

### 2. تحريك كائن
```
1. اضغط W لاختيار أداة الاختيار
2. اضغط على الكائن لتحديده
3. اضغط G لتبديل أداة التحريك
4. اسحب الماوس لتحريك الكائن
```

### 3. تدوير كائن
```
1. حدد الكائن
2. اضغط R لتبديل أداة التدوير
3. اسحب الماوس لتدوير الكائن
```

### 4. تغيير حجم كائن
```
1. حدد الكائن
2. اضغط S لتبديل أداة التحجيم
3. اسحب الماوس لتغيير الحجم
```

### 5. تغيير لون كائن
```
1. حدد الكائن
2. في لوحة الخصائص (يمين)، اضغط "تغيير" بجانب اللون
3. اختر اللون المطلوب
```

### 6. حفظ وتحميل المشاريع
```
حفظ: Ctrl+S أو ملف → حفظ
فتح: Ctrl+O أو ملف → فتح
```

### 7. التصدير
```
ملف → تصدير OBJ
```

## نصائح للمبتدئين

### 💡 نصيحة 1: ابدأ بأشكال بسيطة
ابدأ بإنشاء مكعب وجرب عليه各种 الأدوات قبل الانتقال لأشكال معقدة.

### 💡 نصيحة 2: استخدم اختصارات لوحة المفاتيح
الاختصارات أسرع بكثير من استخدام القوائم.

### 💡 نصيحة 3: احفظ عملك بانتظام
اضغط Ctrl+S بين الحين والآخر لحفظ تقدمك.

### 💡 نصيحة 4: استخدم التراجع
إذا ارتكبت خطأ، اضغط Ctrl+Z للتراجع.

### 💡 نصيحة 5: جرب زوايا مختلفة
استخدم أزرار Numpad (1, 3, 7) لرؤية المشهد من زوايا مختلفة.

## مقارنة مع Blender

### الأوامر المتشابهة

| العملية | Easy3D | Blender |
|---------|--------|---------|
| تحريك | G | G |
| تدوير | R | R |
| تحجيم | S | S |
| تكرار | Shift+D | Shift+D |
| حذف | X | X |
| اختيار | كليك | كليك |
| دوران الكاميرا | زر وسط | زر وسط |
| تقريب | عجلة | عجلة |

### ما يميز Easy3D عن Blender

1. **أسهل في التعلم**: الواجهة بسيطة ومباشرة
2. **أقل استهلاك للموارد**: يعمل على أي جهاز
3. **بدون GPU**: لا يحتاج كرت شاشة قوي
4. **عربي بالكامل**: الواجهة والقوائم بالعربية
5. **سريع التحميل**: يفتح في ثوانٍ
