## Reporting a Vulnerability

If you discover a security vulnerability in Easy3D, please report it responsibly.

### How to Report

1. **Do NOT** create a public GitHub issue
2. Email us at: [your-email@example.com]
3. Include the following information:
   - Description of the vulnerability
   - Steps to reproduce
   - Potential impact
   - Suggested fix (if any)

### What to Expect

- **Acknowledgment**: Within 48 hours
- **Initial Assessment**: Within 1 week
- **Fix Timeline**: Depends on severity
  - Critical: 1-3 days
  - High: 1 week
  - Medium: 2 weeks
  - Low: Next release

### Disclosure Policy

- We will acknowledge your report within 48 hours
- We will provide a timeline for a fix
- We will notify you when the fix is released
- We will credit you in the release notes (unless you prefer to remain anonymous)

## Security Best Practices

When using Easy3D:

1. **Keep Updated**: Always use the latest version
2. **Verify Downloads**: Check file hashes when downloading
3. **Report Issues**: Report any suspicious behavior immediately
