## [2.0.0] - 2024-01-01

### Added
- Complete rewrite in C# with Avalonia UI
- Cross-platform support (Windows, Linux, macOS)
- PBR (Physically Based Rendering) materials
- Texture support (Diffuse, Normal, Specular, Emissive)
- Texture filters (Blur, Sharpen, Emboss, Edge Detect)
- 15 export formats (OBJ, STL, GLTF, Three.js, FBX, PLY, COLLADA, X3D, VRML, USD, AMF, OFF, CSV)
- Import support (OBJ, STL, GLTF, PPLY)
- Multiple shading models (Phong, Blinn-Phong, PBR, Toon, Flat)
- Directional, Point, Spot, and Hemisphere lights
- Software rendering without GPU requirement
- Arabic UI support
- Keyboard shortcuts matching Blender
- Undo/Redo system
- Mesh operations (Subdivide, Decimate, Flip Normals)
- Bounding box visualization
- Transform gizmo
- Grid and axes display
- Multiple camera views (Front, Back, Right, Left, Top, Bottom)
- Camera orbit, pan, zoom
- Ray-based object selection
- Material presets (Metal, Glass, Wood, Rubber, Fabric, Marble, Chrome, Car Paint)
- GitHub Actions CI/CD
- Automated releases for all platforms
